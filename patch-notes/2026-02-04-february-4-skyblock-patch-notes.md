# [February 4] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Added an offline grace period for mutations that spread while the player is offline:
    * First, 3 growth cycles pass normally. After that, a 5 cycle grace period begins, in which they don't grow and don't consume water. If the player hasn't logged on by the end of that grace period, the mutations resume normal growth cycles.
  * Breaking ungrown mutations that would not yield any drops now requires a confirmation (which can be toggled off)
  * Fixed double quantity in pest rare drops message
  * Gave Zombud and Godseed priority over other crops in mutating
  * Fixed Garden Chip SkyBlock XP tasks not showing up in the SkyBlock Guide
  * Fixed more NPCs not accepting Bachelor's Roses sometimes
  * Fixed Watering Cans not carrying over data when upgrading at Farming Essentials in SkyMart
  * Fixed crops dropping while clearing an uncleared plot
  * Fixed Crop Fever Wart "Pray to RNGESUS" level dropping 2 instead of 6
  * Fixed Spooky Bait not mentioning Spooky Festival Requirement in lore
  * Fixed Alchemage Visitor requirement message
  * Fixed being able to apply multiple Etherwarp Conduits to the Aspect of the End

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
