# [February 25] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed Tarantula Fang not having an ability
  * Fixed the launch pad to The Park overshooting the destination
  * Fixed the launch pad to the Gold Mine being off center
  * Fixed the missing lever to leave the Underground Lab on the Farming Islands
  * Fixed the End Stone Protector's name missing space again
  * Fixed a Hoppity egg location using an outdated description for the Wilderness treehouse
  * Fixed a typo in the Blacksmith's tutorial quest objectives
  * Fixed Precision Mining in the Dwarven Mines not respecting latest version crouch height
  * Fixed being able to break part of the Lumber Merchant's house in the Foraging Camp
  * Fixed Romero not appearing in the treehouse when he should
  * Fixed an issue where ex-coop members couldn't guest the profile's island that they left

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
