# [October 13] Some QOL and fixes!

Hello everyone!  
  
Here's some nice quality of life stuff we've added in the latest patch.  
  
**Mushroom Soups**  


  * For some reason soups stopped stacking a while back, this is basically down to the fact that we fight against vanilla Minecraft Mushroom soup mechanics. To help combat this, both custom Mushroom Soups (that give flight) now have custom player head textures and stack properly.  


![image \(1\).png](https://hypixel.net/attachments/image-1-png.2772917/)

  * Nausea is no longer applied when consuming special Mushroom Soups.​


**Other Fixes**  


  * Optimized and added a global limit to Bat Fireworks so there should be less spam/lag from them in hubs.
  * Fixed an issue where players with high ping would have their Booster Cookie flight fail randomly.
  * Fixed flight from Mushroom Soups ticking down whilst a Booster Cookie was active.
  * Added new container checks to the dupe detector, since there were many places players could hide blacklisted items safely.
  * Fixed a bug where the main SkyBlock menu would constantly refresh itself causing it to "flicker".
  * Tweaked our handling of some custom tile entities to help prevent crashes.

  
That's it for now, enjoy!
