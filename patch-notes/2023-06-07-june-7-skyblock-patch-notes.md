# [June 7] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  
**Bug Fixes**  


  * Fixed pets preventing you from placing blocks, even when invisible.
  * Fixed Cleave doing 0 damage to nearby entities.
  * Fixed an issue in custom block breaking zones that caused the mining speed not to update correctly, resulting in being unable to break a block when you should be able to.
  * Fixed an issue in custom mining zones which prevented you from breaking blocks (mostly above the player), very close to the maximum reach distance.
  * Fixed profile menu not being able to display large amounts of Bank Coins.
  * Fixed incorrectly worded error message when applying the 10 Hot Potato Book to items.
  * Fixed not being able to put leashes on Mushroom Cows on Farming Island.
  * Fixed being able to teleport to spawn by going out of bounds and not cancelling the active parkour (e.g. in The End).
  * Fixed a bug that caused Frost Walker enchantment to be active when no boots or boots without the enchantment were worn under very specific circumstances.
  * Fixed (Dungeon's) Archer's Explosive Shot cooldown expiry message sending twice.
  * Fixed (Dungeon's) Archer's Explosive Shot cooldown not being reduced by your Catacombs level.
  * Fixed not being able to interact with Fence Gates when holding specific items.
  * Fixed Quick Crafting suggestions not correctly sorting some recipes that produce varying amounts of the same item.

**Quality of Life**  


  * Added a new icon to the upcoming events menu during the Spooky Festival that can be used to access the Fear Mongerer shop and Spooky Festival rewards from anywhere in SkyBlock
  * You can now ready up by clicking your already selected class in Dungeons.
  * When trying to queue for Dungeons without a party, then navigating to the party finder, it will automatically filter the parties by the floor you tried to queue to.
  * `/ec` now has an optional page argument. For example: `/ec 3` opens the third Ender Chest page.
  * Added a "Right click to open" hint to Sack lores.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
