# [March 24] Various Grammatical Fixes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock! This update focuses on correcting some grammar mistakes in different areas in the game:  
  


  * The Collection Display item now properly refers to the representative skills
  * Fixed many instances of "lifetime" being spelled as "life time"
  * Fixed the Bid Settings notification typo
  * Fixed inconsistencies in the abbreviation for the Heart of the Mountain
  * Fixed a few grammar errors with Season of Joy
  * Fixed the Tarantula Pet referring to Spirit Boots as Thorn's Boots
  * Fixed Slayer Catalyst items duplicating specific lore lines
  * Fixed dialogue errors with Fragilis
  * Fixed a few accessories being suggested in the wrong stage in the Guide Menu
  * Added a confirmation menu to purchasing the Museum Appraisal Service
  * Fixed a typo in the description of the Shark Fin
  * Fixed a few outdated instances of items referring to a "+x% Skill" Perk and not using that Skill's Wisdom stat
  * Fixed Shaggy telling you to collect more items than needed for his quest
  * Fixed grammar issues around the Zombie Miner
  * Fixed Enchanted Red Sand selling for too little at NPCs
  * Fixed many dialogue issues with the Windmill NPC
  * Fixed typo in the description of the Tasty Cheese item
  * Fixed the description of the Whoosh Spray
  * Fixed the Monster Hunter discovery message
  * Fixed grammar errors in many error messages
  * Fixed inconsistent capitalization with names of medals on the player scoreboard
  * Fixed certain items having an un-needed decimal in specific values
  * Fixed dialogue errors with the Kalhuiki Door Guardian
  * Fixed many typos with the telling of the Bear Story
  * Re-worded the Runecrafting description to be more grammatically sound
  * Fixed many rare drops missing the Magic Find symbol in chat
  * Fixed a typo regarding Ice Essence in the Sea Creature Guide
  * Fixed some coloring inconsistencies regarding different Bows
  * Fixed a grammatical issue with the Warden Helmet
  * Fixed many pet descriptions having mis-colored lores
  * Fixed description typo with the Horse and Reindeer pets
  * Fixed multiple message and name descriptions regarding furniture
  * Fixed many description errors for different Families in the Bestiary menu
  * Fixed Lava Death message using "burnt" instead of "burned"
  * Fixed various messages relating to catching different sea creatures.
  * Fixed Arthur's dialogue's grammar
  * Fixed several messages when fighting Bal
  * Fixed the grammar in the lore of pet items
  * Fixed many dialogue lines from Udel & The Dean
  * Fixed dialogue lines during the archaeologist's quest
  * Fixed many lines during the Sadan boss fight
  * Fixed some single tier enchantments having enchant levels in their name
  * The Coco Chopper was renamed to "Cocoa Chopper"
