# [January 23] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  


  * Buffed the drop weight of the Speckled Teacup from 4 to 120.
  * Made Habanero Tactics 5 give 5 Combat Wisdom. Habanero Tactics 4 gives 2.5 Combat Wisdom.
  * Fixed an issue with the Experimentation Table where progress towards the RNG Meter was not deducted if the dropped reward was below 100% progress.
  * Fixed an issue that caused some dyes to display a lower chance than intended on RNG Meters and Boss Drops.
  * Updated the possible Enchanting Experience reward description for Metaphysical Experiments on the Experimentation Table to reflect recent changes.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
