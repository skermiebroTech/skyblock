# Dark Auction Server Patch

Hello,  
  
Today we’ve reduced Dark Auction server size from **20** players to **12**.  
We also changed the minimum player-count in Dark Auctions from **10** to **5**.  
  
Fewer players per server means less overbidding and more players actually walking away with items.  
  
We’ll keep an eye on how this impacts prices and availability.  
  
That’s it for now!
