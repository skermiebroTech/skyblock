# [August 11] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock, containing a whole bunch of changes to last week's [0.27 Release](https://hypixel.net/threads/hypixel-skyblock-0-27-torrhus-canyon-critter-safari.6132090/)!  


  * Added the Honey Guide to /guides
  * Added an Abiphone Contact to Archie
  * Added a fancy new skin to the Grizzly Bear
  * Added more possible Hideyho spawns
  * Added a time breakdown to the Reward Summary
  * Added Signal Enhancers to the Bazaar
  * Added Sepialot spawns to the Spring Path
  * Added SFX that triggers when the beige half of a Helix Tree is completely cut
  * Added "Amphibian" family to several shards:
    * Sepialot
    * Goldolot
  * Allowed for players to stack bird baits of the same type in the Birdfeeder
  * Allowed for Pickaxe Abilities to be used on Torrhus Canyon
  * Increased Karma enchantment drop chance from 0.02% -> 0.2%
  * Increased chance of Goldolot spawning in place of a Sepialot from 10% -> 20%
  * Increased the speed at which birds are attracted to the Birdfeeder. Maximum wait decreased from 30s -> 10s
  * Increased base yield of Ruby Veilshrooms from 1 -> 4-8
    * Rarer Sea Creatures can now even drop Veilshroom Bunches directly!
  * Increased Ruby Veilshroom gain from Torrhus Sea Creatures
  * Improved the successful charm activation message
  * Improved Miria's contest complete announcement
  * Improved the successful shard trade message
  * Improved Hideyho dialogue
  * Improved chat color consistency in "That's not a Critter..." messaging
  * Improved the itemlore of the various Uncommon Boosters and renamed them:  


    * Uncommon Sweep Booster → Uncommon Sweep Booster Upgrade
    * Uncommon Fighting Booster → Uncommon Fighting Booster Upgrade
    * Uncommon Foraging Fortune Booster → Uncommon Foraging Fortune Booster Upgrade
    * Uncommon Foraging Wisdom Booster → Uncommon Foraging Wisdom Booster Upgrade
    * Uncommon Hunting Wisdom Booster → Uncommon Hunting Wisdom Booster Upgrade

  * Merged the Sepialot and Goldolot Bestiaries
  * Adjusted Pangolin detection to be based upon line of sight instead of a flat radius
  * Adjusted all Torrhus Sea Creature Bestiaries to be in line with other modern Sea Creature Bestiaries of the same tier
  * Adjusted Hunter Jean's menu to use mob skulls instead of items
  * Adjusted the Bestiary description of the Tikis
  * Adjusted how End Stone Protector shard is obtained:
    * Now awarded to to all players with 240+ weight
  * Adjusted the Gazer spawn SFX, making it a little spookier
  * Adjusted Frog Pet, re-ordering its perks and revamping "Hunting Enjoyer" to specifically work on Water Shards
  * Adjusted Fusion Machine SFX to be client-side
  * Adjusted HOTF/HOTM menus to utilize stacked glass panes to better display which tier of the tree you're looking at
  * Adjusted Beeheemoth to no longer passively regain stamina while not lassoed
  * Adjusted the spawn amounts of some Critter Safari mobs:
    * Areita: 2-4 -> 3-6
    * Billygoat: 1 -> 2-4
    * Bloodbat: 2-4 -> 3-6
    * Tepid: 8-12 -> 6-8
    * Gazer: 2 -> 4
    * Flitter: 3-6 -> 6-8
    * Foxtrot: 3-6 -> 6-8
  * Adjusted locations and amounts of some Floor Drops in the Critter Safari:
    * Yogi Berry: 3-6 across all biomes -> 3 guaranteed in Forest Biome
    * Wriggleworm: 3-6 across all biomes -> 3 guaranteed in Forest Biome
    * Bag of Seeds: 3-6 across all biomes -> 3 guaranteed in Forest Biome
  * Adjusted Starborn Temple door to shut behind players like the Moonglade Marsh one does
  * Adjusted some Chapter tasks:
    * Moved “Obtain Ruby Veilshrooms” from Chapter 3 → 4
    * Moved “Craft a Fun-Sized Pot of Honeycomb” from Chapter 4 → 3
  * Adjusted "BEEHEEMOTH DOWN!" message to no longer display to players who dealt 0 damage
  * Reduced amount of Ruby Veilshrooms used in Accretion Artifact from 16 -> 2
  * Reduced max kills required for most types of Critter Bestiary:
    * COMMON Shard: 300 -> 125
    * UNCOMMON: 150 -> 100
    * RARE: 75 -> 75 (unchanged)
    * EPIC: 50 -> 50 (unchanged)
    * LEGENDARY: 25 -> 25 (unchanged)
  * Reduced weight of Queen Bee Shard in Honeyhives from 25 -> 10
  * Reduced Safari Milestones for each Biome:
    * Milestone I: 5 -> 5 (unchanged)
    * Milestone II: 25 -> 25 (unchanged)
    * Milestone III: 50 -> 50 (unchanged)
    * Milestone IV: 100 -> 100 (unchanged)
    * Milestone V: 250 -> 150
    * Milestone VI: 500 -> 250
    * Milestone VII: 750 -> 350
    * Milestone VIII: 1,000 -> 450
    * Milestone IX: 1,250 -> 600
    * Milestone X: 1,500 -> 750
  * Reduced Water Snake HP from 3,000 -> 1,000
  * Reduced the speed of Litterbugs by 25%
  * Removed "Elusive" mob type from the Lunar Moth
  * Removed additional Fighting Booster flavortext from items
  * Removed True Damage from Torrids and Silkbreeze
  * Removed Sea Lumies from Hotspot Haven
  * Renamed Worm -> Stoneworm
  * Added Hunter Reeves' brothers so he does not show up multiple times
  * Fixed Hideyho "flying" towards its hiding spot instead of instantly teleporting
    * The Hideyho now leaves vague footprints in the direction of its hiding spot
  * Fixed one of Torrhus Canyon's Helix Trees not allowing you to break the Beige Logs first
  * Fixed the "Claim All" option in the Starlyn Sisters menus awarding Bits even if you had no Bits available

If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change. Changes/fixes to unobtainable fusions and Hunting XP gains from the Safari Zone are a WIP._
