# [June 14] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed some Vanilla items being shown in the Quick Craft menu instead of more valuable SkyBlock items. [If there's more cases like this, please submit a bug report!](https://www.hypixel.net/skyblock-bugs/)
  * Fixed status effects not applying correctly when joining Crimson Isle.
  * Fixed candy from Fear Mongerer commission in Garden not going into sacks.
  * Fixed a few formatting issue on the scoreboard in Dungeons.
  * Fixed the per-player loot drops (e.g. from Dragon fights) not being centered on the block they spawn on.
  * Fixed holograms blocking the Minecart when trying to travel to Crystal Hollows.
  * Farming Hoes now send a chat message when their rarity increased due to farming.
  * Fixed Melody not listing perfect song completion rewards, if not finished on the first attempt.
  * Fixed Silent Pearls being disabled in Guber's End Race.
  * Slightly improved pet item description.
  * Moved the anniversary NPC to a location closer to the Hub spawn.
  * Fixed a few server crashes.
  * Fixed Coin Talisman sometimes spawning invalid items.
  * Fixed Hunter Ring craft not transferring over Recombobulators.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
