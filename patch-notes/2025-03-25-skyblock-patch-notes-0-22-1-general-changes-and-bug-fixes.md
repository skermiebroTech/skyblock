# SkyBlock Patch Notes 0.22.1 - General Changes and Bug Fixes

Hello!  
  
Welcome to **Hypixel SkyBlock Patch 0.22.1**. Today’s update has a few minor changes and bug fixes.  
  


### **►** General Changes​

  * Added a way to check how many times the Experimentation Table has been refreshed in the day.
  * Added a Garden Level requirement to Emissary Sisko.
  * Added Dung Dye to all Pest Drops in the Pest Handbook.
  * Added Fruit Bowl as a rare reward from Garden Visitors.
  * Added Divine Gift II and III to the Bazaar.
  * Added Sulphuric Coal to the Nether Sack.
  * Book of Stats is now applicable to Wands.
  * Changed Gemstone Gauntlet to only loot share gemstones to players who also attacked with a Gemstone Gauntlet.
  * Changed Glowing Mushroom Cave name color to aqua.
  * The Enderman Slayer Level 9 Perk now grants an increased chance for a Superior Dragon to spawn.



### **► Bug Fixes**​

#### Garden Fixes​

  * Fixed Garden plot prices for some people who had some of their progress reset due to a past issue.
    * Refunded players who, as a result, paid extra for their plots.
  * Fixed visitors, pests, and composter offline progress resetting when getting kicked from the Garden.



#### Item Fixes​

  * Fixed Extremely Real Shuriken description only specifying "when killed by you" instead of any player.
  * Fixed Giant Bouncy Beach Balls not popping when hitting a wall.
  * Fixed **Magma Lord Armor’s Fireproof ability** requiring the full 5-set instead of 2 for activation.
  * Fixed "Storm/Thunder/Hurricane in a Bottle" all filling when in inventory.
  * Fixed the Vanquished Equipment Stat bonuses applying twice.



#### Enchanting Fixes​

  * Fixed an issue where the Experimentation Table was closing if you bought experience.
  * Fixed being able to apply the Golden Bounty item to Scavenger Books.
  * Fixed being able to buy experience bottles from the Experimentation Table on Stranded/Ironman modes.
  * Fixed Experimentation Table’s RNG Meter not displaying accurate odds for Ultra Rare items.
  * Fixed Ultimate Wise not reducing the mana cost of the Maniac Miner ability.



#### Fishing Fixes​

  * Fixed coins caught from fishing not showing in the scoreboard.
  * Fixed fishing rods with soulbound rod parts not being soulbound.
    * To clarify: Applying a soulbound rod part to an unsoulbound fishing rod will temporarily soulbind the fishing rod. Removing the soulbound rod part will unsoulbind the fishing rod.



#### Pet Fixes​

  * Fixed being able to use some disabled bows with the Skeleton Pet’s "Skeletal Defense" perk.
  * Fixed Goblin Pet’s "Fetid Thief" perk incorrectly displaying the name of the perk.
  * Fixed Magma Cube Pet’s "Slimy Minions" perk description not mentioning working on Magma Cubes.
  * Fixed Reindeer’s "Icy Wind" ability not doubling Ice Essence when killing Winter Sea Creatures.



#### Misc. Fixes​

  * Fixed a double space in the Flaming Fist item description.
  * Fixed a typo in Pandora's Box item description.
  * Fixed a typo in the Ember Armor full set bonus description.
  * Fixed a typo in the Griffin Pet's Odyssey Perk.
  * Fixed a typo in the Jerry Box click description.
  * Fixed a typo in the Kuudra Believer intro dialogue.
  * Fixed a typo in the Skeleton's Helmet Ability message.
  * Fixed Arthur's Wheat Minion in the Hub having a Compactor.
  * Fixed being able to buy rabbits that you don’t meet the requirements for from Hoppity over the phone.
  * Fixed being able to place Enchanted Clay Blocks on Private Islands.
  * Fixed being unable to select Mithril Grubbers in the Bestiary Widget in the Dwarven Mines.
  * Fixed Fiery Burst Rune not working with Cactus Knifes.
  * Fixed Finnegan's GOATed perk not applying to some contests.
  * Fixed Ice Minions being 5% faster for no apparent reason.
  * Fixed inputting custom prices with commas giving incorrect prices.
  * Fixed minion and furniture counts being off by 1.
  * Fixed Rhinestone Infusion (Diamond Essence Shop Perk) giving more SkyBlock XP than intended.
  * Fixed Sirius' name being the wrong color in Lucius' dialogue.
  * Fixed Spooky Festival bits rewards sometimes not being granted.
  * Fixed "Starred" items from not counting toward Madame Eleanor Q. Goldsworth X's quest.
  * Fixed the particle quality toggle not affecting Gemstone Crystal particles.
  * Fixed the SkyBlock Guide’s Mythic Rabbit section showing an incorrect amount of rabbits.
  * Fixed the RNG meter re-selected message showing twice in some scenarios.
  * Fixed usage of /wikihand with Enchanted Wheat showing a non-existent page.



### **► Hotfixes**​

These are issues that popped up during the release that we fixed.  


  * Fixed Loot Share not working.
  * Fixed Lava Rods not being able to be cast in lava.
  * Fixed Ultimate Wise not working on wands.
  * Fixed Magma Lord Armor’s Fireproof ability requiring the full 5-set instead of 2 for activation, again.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
