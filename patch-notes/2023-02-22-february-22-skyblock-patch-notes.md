# [February 22] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed Fermento Armor being uncraftable
  * Fixed Fermento Armor not working
  * Fixed being able to use the Block Zapper on custom presets to "transfer" blocks out
  * Fixed new farming armor sets proccing on immature crops
  * Clearly state that you must be on the Garden in order for crops to paste on plots
  * Fixed Garden Crop Milestone task going to the Visitor Milestone menu in SB Levels
  * Fixed Sam spawning in non-solid blocks on private islands
  * Spelling and description consistencies
  * Fixed being unable to use the Nether Wart Pouch on the Garden
  * Mycelium is back to being exclusively in the Mining section of the Bazaar
  * Fixed composter removing non-existent items from sacks
  * Fixed getting soft-locked out of Sam's Purchase a Plot objective. If you are stuck here, try clicking on her to update it!
  * Fixed getting mushroom commissions requiring more mushrooms than a player can hold. There are now a couple of new mushroom recipes
  * Fixed coop members not receiving Garden milestone rewards if they were offline
  * Fixed visitor powder rewards sometimes giving a different powder type than the type shown in the list of rewards
  * Reduced farming xp from visitors
  * Reduced copper rewards from visitors **(Notice: This nerf happened only once before this patch was rolled!)**
  * Fixed island crystals bypassing Garden Level requirements for planting crops
  * Build Height Changes - full thread [HERE](https://hypixel.net/threads/regarding-garden-height-limit-changes.5282682/)
    * New build height is 10 blocks high from bedrock level
    * Blocks currently above this new build height can be broken, but no new ones can be placed
    * Existing presets will not paste blocks above the new height limit
    * Pasting new presets will remove old blocks above the new height limit
    * Nether Wart and Mushroom growth speed is increased. Mushroom growth is no longer capped by the amount of mushrooms around them
    * The new farming armors grant more farming fortune
    * [COMING SOON] Overall crop growth speed is increased per garden level

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
