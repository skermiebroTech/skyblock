# Hypixel SkyBlock 0.24.1 - Swappable Pet Items, Garden Changes, & Bug Fixes

![banner.png](https://hypixel.net/attachments/banner-png.3536869/)

  
Hello! Today we are releasing **Hypixel SkyBlock 0.24.1** which features Swappable Pet Items, some miscellaneous changes, and a _ton_ of bug fixes. Keep reading for all of the details!  
  
  
**►** **Swappable Pet Items**  


![swappable_pet_items.png](https://hypixel.net/attachments/swappable_pet_items-png.3536719/)

  
You are now able to swap Pet Items on your Pet without deleting their currently equipped Pet Item. The cost of the swap process depends upon the rarity of the item being **replaced** :  


  * **COMMON** : 25,000
  * **UNCOMMON** : 50,000
  * **RARE** : 100,000
  * **EPIC** : 250,000
  * **LEGENDARY** : 500,000
  * **MYTHIC** : 1,000,000 (Futureproofing)
  * **DIVINE** : 2,500,000 (Futureproofing)

  
**►** **Miscellaneous Changes**  


#### **➥ Garden Changes**​

  * Changed the Rosewater Flask to cap at 4 Growth Stages and only work on the Greenhouse Plot the player is standing in
  * Added Decay time info to the Diagnostics Tool
  * Added info on how long crops will stay watered for to the Diagnostics Tool
  * Added message in Diagnostics Tool Menu to show if a crop has enough water to fully grow
  * Improved time displays in Diagnostics Tool Menu
  * Added the item amount to the message given when dropping rare items from pests
  * Added a message to the Plot Limit upgrade icon, clarifying that new plots come with the slots already unlocked
  * Added Sunflower Oil and Bachelor's Rose to the Bazaar
  * Added lore to the Voter's Badge accessories to show progress towards the next tier



#### **➥ Pet Item Changes**​

  * Plumber Joe now sells a Super Scrubber for 25,000 Coins
    * This item allows you to retrieve a Pet Item from a Pet without applying another one in its place
    * You still have to pay the corresponding swap cost
  * Adjusted the rarities of several Pet Items
    * Increased rarity of All Skills Super-Exp Boost from **COMMON** → **UNCOMMON**
    * Increased rarity of Quick Claw from **EPIC** → **LEGENDARY**
    * Increased rarity of Brown Bandana from **RARE** → **EPIC**
    * Decreased rarity of Washed-up Souvenir from **LEGENDARY** → **EPIC**
    * Increased rarity of Dwarf Turtle Shelmet from **RARE** → **EPIC**
    * Adjusted the rarity of all mythic-upgrading pet items (e.g. Scuttler Shell) to **MYTHIC**
  * Updated the descriptions of all Pet Items
  * You can no longer recombobulate Pet Items



#### **➥ General Changes**​

  * Added a tool level requirement to the Overclocker 3000.
  * Added shapeless crafting recipe for Enchanted Cookies.
  * Added Sparrow and Seagull Shard Recipes to the Recipe Book and Quick Crafting.
  * Added support for Bal in the boss spawn pet rule.
  * Added Wet Books to the Hex.
  * All 10 Hot Potato Books now must be applied before applying any Fuming Potato Books.
  * Changed Pet Luck description to be more clear.
  * Expanded the Oasis zone in the Farming Islands to include the other pools of water.
  * Gave Royal Resident better names to avoid confusion.
  * Increased the Jungle Pickaxe Heart of the Mountain requirement from level 3 to level 4.
  * Pests now have 2 stamina bars when lassoing since kill credit is granted.
  * Removed Mushroom Desert travel pet rule.
  * Stereo Pants music discs no longer count as a treasure catch, and now give a custom message when fished up instead.
  * Gemstone Gauntlet's Kinetic ability now only has 1 second cooldown instead of 2 seconds



#### **➥ UI Changes**​

  * Improved the Flaming Fist description to be more clear on how it deals damage.
  * Removed the "Unknown Map" label under an icon in the SkyBlock Guide.
  * Updated some dye sources in Vincent's menus with mob types.
