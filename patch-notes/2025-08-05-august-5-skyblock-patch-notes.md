# [August 5] SkyBlock Patch Notes

Hi,  
  
Since the release of [Hypixel SkyBlock 0.23.3](https://hypixel.net/threads/hypixel-skyblock-0-23-3-foraging-changes-mob-types-and-more.5963817/), we have deployed some further improvements to the game:  


  * Increased the Crit Damage of the Dark Claymore from +30% -> +100%.
  * Added +100% Crit Damage to the Tormentor.
  * Adjusted Quazii to be the "Skeletal" mobtype.
  * Adjusted Typhoeus to be the "Wither" mobtype.
  * Adjusted the Wither Skeleton pet's perks to utilize the new Mob Type system.
  * Fixed an issue allowing for several huntable Moonglade Marsh mobs to be killed with Ability Damage.
  * Fixed an issue causing Hunting Fortune to not be applied while on Private Islands.
  * Fixed an issue causing The Primordial to remove the Mob Types of mobs it cocooned.
  * Fixed an issue causing Smite VII to drop from Zombie Slayer instead of the Severed Hand drop.

If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
