# [November 21] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Finally fixed an issue where some players would end up with a negative collection amount
  * Fixed Block Zapper not removing certain, usually colored, blocks properly
  * Made Block Zapper work with sacks and personal deletor
  * Fixed Block Zapper preventing melon and pumpkin stem zapping with a weird message
  * Slayer bosses now have a hologram above them saying who owns them
  * Museum scroll is now visible in Special Recipes in the Recipe Book

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
