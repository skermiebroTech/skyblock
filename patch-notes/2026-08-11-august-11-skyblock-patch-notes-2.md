# [August 11] SkyBlock Patch Notes 2

Hello!  
  
We have more fixes ready for you today, as follows:  


#### **➥ Shard Fusion Fixes** ​

  * Fixed Shard Fusion not prioritizing shards with a higher rarity.
    * The Shard Fusion system before Torrhus prioritized ID Fusion before Special Fusions.
    * This is now no longer the case, Special Fusions will appear before ID Fusions.

**Quick Note:** It is intended that you can no longer ID-Fusion into the Power Dragon shard as it defeats the purpose of the intended obtainment method (M7). This reasoning is also why we made similar changes to some other shards on Torrhus Canyon's release, being able to ID-Fuse into certain shards completely bypasses the intended obtainment method.  
  
Regarding the Power Dragon Shard:  


  * You can still obtain the Power Dragon shard from Hellwisp through the usage of a Chameleon shard, that is intended behavior.
  * If the current obtainment method of the Power Dragon shard (M7) is inadequate, please explain why that's the case, and suggest potential solutions or improvements that don't outright bypass the intended obtainment method.



#### **➥** Lava Bouncing in F7/M7 ​

**PSA** : Following these changes, you should play on Minecraft Version 26.1+ for optimal lava jump behavior.   


  * Adjusted the Lava Bouncing mechanic in F7/M7 to be closer to existing behavior on latest versions:
    * There are now two types of lava jumps, _regular_ and _super_.
    * The regular jump height is slightly higher than before (in 1.21.11 and lower).
    * Looking upwards (pitch of -40 or "lower") triggers a super lava bounce, letting you bounce 30% higher than a regular jump.

Let us know if some/all of these parameters need further adjusting.  


  * We can lower the default jump height if that's preferred.
    * After doing some testing in Goldor's phase, we think there's a chance the new slightly higher jump height may be preferred -- the old jump height was insufficient at times to bounce back to certain platforms.
  * We can adjust the pitch required to trigger a super lava jump.
  * We can adjust the height of the super lava jump, if necessary.

**EDIT** : Jump heights have been adjusted to be higher compared to the initial roll.
