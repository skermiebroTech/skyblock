# [July 27] Bug fixes

Hey everyone!  
  
I'm MFN, a new SkyBlock developer at Hypixel! I've been working on some bug fixes and changes that are listed below:  
  


### ******► ****Bug Fixes**​

  * If your inventory is full when a special Zealot drops a Summoning Eye, it now goes to your stash
  * The Blessing fishing rod enchantment now drops multiple single-item stacks (e.g. Music Discs)
  * Pickobulus ability no longer breaks portal blocks
  * Precursor Eye lazer is now deactivated when swapping helmets
  * Firework Star is no longer listed twice when choosing a Storage Ender Chest icon
  * Goblin eggs no longer hatch in the Dungeon Hub
  * InfiniDirt wand now works with farmland blocks
  * Trick or Treat Chest drops can no longer be picked up by other players
  * When leveling up, the Pristine enchantment now has a tooltip
  * Aurora Staff no longer fires through blocks
  * Dying while riding an Armadillo or Rock no longer teleports you back to them on death
  * Jax shows Sell hopper instead of Close barrier
  * Blast o' Lantern can no longer be placed
  * NPC shops now show the correct amount purchased when bulk-buying
  * Fixed bypassing NPC shop daily purchase limit
  * Fixed clipping through walls using the Horse pet
  * Fishing bag now only contains fishing items
  * InfiniTorch no longer takes money when you can't place it
  * Farming for Dummies enchanted book displays Farming Fortune stat in the Anvil menu
  * Crafting a new minion or joining a co-op now notifies co-op members using your actual username and rank
  * Fixed God Potions and other effects wiping in Dungeons



### ****► ****Other Changes​

  * Equipping a Skeleton Helmet no longer starts with 3 bones; though it regenerates as normal

  
That's all for now and I hope you continue to enjoy SkyBlock ![:hypixel_smile:](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7)
