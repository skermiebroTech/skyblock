# [June 1] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed an issue where Iceberg Dyes would not drop from Winter Sea Creatures
  * Fixed an issue with Shark Bait granting a much lower chance to fish Sharks than intended
  * Prevented Cactus from growing in invalid locations
  * Updated the world version of all islands to 1.21.9
    * This is only a preliminary step towards creating other latest required content.
    * This does NOT change the builds of any islands. If you happen to notice any issues, please report it!
    * This does allow placing Paintings from 1.21.9 and previous versions on Private Islands.
  * Fixed some miscellaneous typos

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
