# [March 21] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed Perfect Heist being awarded when player took damage.
  * Fixed mushrooms from the Mooshroom Pet not counting towards Mushroom Crop Milestone.
  * Players can no longer push Jake's cows.
  * Fixed Fermento Armor set bonus awarding Farming Fortune when the set requirement isn't met.
  * Fixed an exploit with the Builder's Ruler.
  * Fixed lamps disappearing when attempting to place in the Garden.
  * Players can no longer spawn snowmen in their Garden.
  * When buying resources from the bazaar, always buy the full plot amount.
  * Fixed getting the achievement Quite the Crowd as a visitor.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
