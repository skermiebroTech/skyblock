# [December 13] Rift Mountaintop Fixes

Hey all!  
We are here to inform you about the last three days' worth of bug fixing in SkyBlock!  


  * Fixed a softlock from Ubik's Split or Steal minigame.
  * Fixed a softlock from becoming Wizardman.
  * Fixed Extremely Real Shurikens not affecting slayer bosses.
  * Added Highlite to the Bazaar.
  * Made Knitting Needle work with slayers.
  * Fixed the Split or Steal game cooldown sometimes not applying.
  * Fixed the 7th Sin Porhtal Eye respawning when fighting it.
  * Implemented a refund for the Time Chamber when the server restarts.
  * Increased the difficulty of the Wizardman Brawl.
  * Increased duration of the Walk of Fame doors being open.
  * Added a Gold Collection X requirement to the Enchanted Clock.
  * Made aging items only able to be affected by Enchanted Clocks every 48 hours.
  * Added Sharp Steak Stake to the Vampire Slayer recipes menu.
  * Fixed being able to use Free Will on other players' minions.
  * Fixed multiple End Nodes spawning inside the same block.
  * Fixed non End Node purple clay blocks being breakable.
  * Fixed being unable to enter the same number as the last revolution in the Ubik Averages game.
  * Fixed the Old Timer calling the player from a little too far away.
  * Fixed an exploit with the Wizardman Brawl.
  * Fixed an exploit with the Time Pocket.
  * Fixed player icons not showing up in the tablist on the latest Minecraft version.
  * Fixed the tablist for Jerry's Island being inaccurate for the time the island is open during December.
  * Fixed the dialogue for jumping in the Wizard Portal without an Infusion coming from the Wizard instead of the Wizard's Assistant when the Wizard isn't there.
  * Fixed the Sun Gecko EXP leaderboard unlocking sooner than mentioned.
  * Fixed being able to open Generow's Menu and the SkyBlock Advent Calendar menu in Rift.
  * Fixed Super Leech Modifier not mentioning it decreases mana cost.
  * Changed the S Logo to a W Logo.
  * Fixed some missing commas, typos, and formatting issues.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
