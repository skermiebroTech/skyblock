# [August 23] Patch 0.14 Bug Fixes 2

Hello!  
Some more fixes following [0.14](https://hypixel.net/threads/5074247/)!  
  
**General**  


  * Buffed Speed in Dungeons by changing the overflow nerf from 0.33x to 0.66x
  * Fixed Stats Cap calcutations:
    * Made sure to use the uncapped value for things which need it (For example Snail, Overload...)
    * Cap post-multiplier (Warden Helmet) now applies on the cap after overrides to fix interaction with Rancher Boot
  * Fixed Overload never proccing and changed the hit icon when it does
  * Fixed Drills still granting their innate stats when their fuel is empty. Drills will now also hide their gemstone-specific stats bonuses when empty
  * Fixed not being able to place Beacons on your private island
  * Fixed /sethome only working on first respawn
  * Fixed magic damage being so small you needed a microscope
  * Fixed Auto-Recombobulator and added a setting to toggle its chat message



![1661237008715.png](https://hypixel.net/attachments/1661237008715-png.3073131/)

  
Auto-Recombobulator is fixed and has a chat toggle​

  
**Pandora's Box**  


  * Added a check to ensure Revenant Slasher is being completed by a player as well as the right player
  * Made sure to reset Crypt Exploder when the player leaves
  * Disabled Custom Damage on Dragon Puncher
  * Fixed times not being saved properly on the challenges
  * Fixed /equipment having 2 close buttons
  * Fixed the Shen claim button appearing wrong under certain conditions

**Tiny Stuff**  


  * Removed vanilla attributes from Bazaar category buttons
  * Now displaying the proper amount of Slayer recipes in the menu
  * Fixed some formatting in George's menu(s)
  * Formatted the description of Prehistoric Egg
  * Fixed Drill Engines showing Mining Speed twice instead of the fortune it grants
  * Always hide stats with amount 0 in the top-level stats menu

Enjoy!  
More to come!
