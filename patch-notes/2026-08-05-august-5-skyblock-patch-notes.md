# [August 5] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock! These are fixes relating to yesterday's 0.27 release.  
  


  * Fixed being able to warp in people without Heart of the Forest 4 into Torrhus Canyon.  
Note: If you were previously on an older Critter Safari instance, or an older server, you may have to swap to a hub before being able to rejoin the Torrhus Canyon.
  * Fixed Helix Logs not counting for the Absorb Enchantment.
  * Fixed the "Obtain x Shards using a Lushlilac Bonbon" chapter tasks not completing correctly.
  * Fixed Lotus Atoll being missing from the /warp menu.
  * Fixed Grizzly Bears getting stuck in the terrain.
  * Fixed not being able to drag Soulbound items into the Reclaim Menu.
  * Fixed an issue with Pest pathfinding where they would all go to the center of empty plots.

  
If you have a bug to report to us following these changes, please do so [HERE!](https://www.hypixel.net/skyblock-bugs/)
