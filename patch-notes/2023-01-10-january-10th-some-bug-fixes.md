# [January 10th] Some Bug Fixes

Hey all!  
  
Today we have rolled a collection of bug fixes and tweaks to the game:  


  * Fixed Wither Cloak shield remaining when you die in Dungeons or Kuudra
  * Fixed Wither Cloak ability not having the correctly reduced cooldown as Mage in Dungeons
  * Fixed Wither Cloak cancelling immediately if you deactivate and activate the ability before the first activation would have expired
  * Fixed a bug with the Thorn Spirit Bow which caused the bow to be removed incorrectly if you get it again too quickly
  * Fixed Wolf Fur Mixin effect not working
  * Fixed Ghoul Pet Reaper Soul perk not increasing Reaper Scythe minion health
  * Fixed Parrot Pet mimic still display message when you have chat disabled
  * Fixed Bonzo Mask and upgraded Bonzo Mask having separate cooldowns allowing for double the ability usage
  * Fixed Kuudra sometimes submerging downwards during Phase 4
  * Fixed lower tier Kuudra Core accessories counting towards MP/stats when you have a higher tier equipped
  * Fixed the message when you hit Kuudra with an Energized Chunk displaying the incorrect amount of time added
  * Fixed Slayer bosses despawning on the End Island when a Dragon is killed
  * Fixed Protector Dragon armor perk increasing stats other than Defence
  * Fixed a bug which sometimes allowed a player to double kill a mob with the Dark Claymore
  * Fixed Kuudra Dropship TNT, Bonzo's explosive Balloons and the Power Dragon's TNT Bomb not dealing true knockback
  * Fixed an exploit with dropping Training Weights on join
  * Fixed some Jerry's Workshop mobs not being blacklisted from the Totem of Corruption effect
  * Fixed North Stars counter not always appear in the scoreboard when on Jerry's Workshop
  * Tweaked Lava Bounce code to make it more reliable in Dungeons and Kuudra
  * Tweaked the Line Up Terminal puzzle in the Floor 7 Dungeon boss fight to be less laggy and more responsive
  * Tweaked the Phoenix Pet Rekindle Perk to work more similarly to the Spirit Mask ability and to put you back to half health on activation
  * Tweaked doors in Dungeons to open slightly faster
  * Tweaked Fresh Tools Kuudra Perk to scale from 2->4->6->8->10% to 5->7.5->10->12.5->15%
  * Tweaked mobs spawned by minions to no longer have collisions, damage indicators and health holograms
  * Tweaked the December shop requirement to be clearer

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
