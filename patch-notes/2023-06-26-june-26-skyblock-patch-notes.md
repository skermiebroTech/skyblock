# [June 26] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  
**Bug Fixes**  


  * Fixed some Sea Creatures not giving Fishing EXP when killed.
  * Fixed using Midas Staff spamming Superboom TNT messages.
  * Fixed Metal Detector sometimes not activating correctly when held in hand.
  * Fixed always respawning at the same entrance in Crystal Hollows when dying.
  * Fixed Ascension rope always bringing you to the same spawn when used, regardless of your actual spawn location.
  * Fixed Bazaar confirmation menu when selling all inventory items not closing.
  * Fixed pet stat bonuses not including a "+" in the lore for values smaller than 1.
  * Fixed some numbers not being formatted correctly.

**Quality of Life**  


  * Added a `/backpack [slot]` command. Example: `/bp` or `/bp 3`
  * Added an optional page argument to `/wardrobe`. Example: `/wd 2`
  * Added a cooldown to some warning messages in Crystal Hollows.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
