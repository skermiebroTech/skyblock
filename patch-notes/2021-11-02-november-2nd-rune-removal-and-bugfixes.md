# [November 2nd] Rune removal and bugfixes

Hello!  
  
This patch brings a new feature, as well as some bug fixes.  
  
**Rune Removal**  
The Rune Pedestal has a new option, where you can remove runes on items free of charge! This process will, however, destroy the attached rune forever.  
  
**Bug Fixes**  


  * Fixed an issue where coops would sometimes not gain the correct amount of items in their collection​

  * Fixed an issue where the collection would go into negatives if more than 2.1 billion items were collected​

    * You now can collect up to 9 quintillion items into collections. We're assuming this will be enough for the foreseeable future.​

    * ~~Please note: This change may take a few hours to roll out fully. We will update this thread when it is enabled.~~ ​

      * This feature is now enabled.​

    * Players who previously went over the limit and now have a negative collection will be fixed soon.
  * Fixed an issue where the teleport ability of wither impact would not work on private islands​

  * Fixed an issue where items with right-click abilities would trigger their ability when interacting with interactive blocks (chests, furnaces, etc.)​

  * Fixed an issue where the reaper set would not apply the healing bonus to healing wands​

  * Fixed an issue where some temporary stat modifiers would not work​

    * Most notably is the Final Destination and Reaper sets' bonus defense.​




#### Extras​

  * The in-game day count is now randomized in Crystal Hollows and End Island.
    * We are aware that it can be annoying if you join a crystal hollows instance when it has almost no time left. To counter this, we are making changes such that you will spawn in crystal hollows instances which have sufficient time remaining before they close. We are also looking at increasing the total time a crystal hollows instance has before it restarts.
  * The Melody's Harp minigame now uses a ping offset so you should be able to get some more accurate scores!
