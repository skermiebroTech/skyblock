# [March 18] SkyBlock Patch Notes

Hey!  
We have just rolled an update to SkyBlock that contains several bug fixes and small changes.  
  


  * Fixed Summoning Eyes count not showing correctly in the tablist.
  * Fixed not being able to select Fishing Bestiary families on The Park tablist.
  * Fixed election candidates perk count sometimes being incorrect in the tablist.
  * Fixed orbs trying to activate when walking over pressure plates.
  * Fixed some typos, grammar and formatting.
  * Fixed /viewpotion not working when providing capitalized IDs.
  * Fixed Edible Mace working on non-melee damage.
  * Fixed being unable to obtain Alixer's abiphone contact.
  * Fixed "Skilled" community Bingo goal using the wrong type of experience.
  * Fixed a bug that caused rune particles from armor to appear when not wearing it.
  * Fixed "Knowledge is Power!" achievement awarding when equipping a pet with the Textbook item.
  * Fixed Sweet Axe perk not working when enchanted with Silk Touch.
  * Fixed Scatha's Wormhole perk breaking protected blocks.
  * Fixed incorrect boss collection progress shown in menu.
  * Fixed Sneaky Creepers not dropping Smokey Runes.
  * Fixed Minions placing blocks outside the island boundaries.
  * Fixed Bestiary menu showing incorrect progress when on a Stranded profile.
  * Fixed Ender slayer enchantment not working on Endermites.
  * Fixed a bug that caused an auction's time to be set to an incorrect duration.
  * Fixed being able to heal from taking damage with a very high defense value.
  * Fixed getting a stash message when joining an island as a guest.
  * Adjusted the progress earned from breaking blocks in Garden. Also now counts blocks one block lower than before. While there might be a different underlying issue, this should prevent new plots from being "uncleanable". For existing and cleared blocks, try placing dirt blocks at y = 70 or higher and break them again.
  * Changed Blood Scent's damage bonus to be additive instead of multiplicative.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
