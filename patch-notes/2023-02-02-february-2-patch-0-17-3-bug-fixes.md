# [February 2] Patch 0.17.3 Bug Fixes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed a bug that prevented SkyBlock XP from Dojo Rewards that had been skipped.
  * Fixed a bug that caused glass panes to be removed from Kat and George's menus
  * Fixed the Guide Menu suggesting Seeds Collection VII and Lily Pad Collection X
  * Rebalanced many Guide Menu suggestions
  * Fixed many grammatical issues in the Guide Menu
  * Fixed an issue where SkyBlock Level could be incorrectly shown as 0
  * Fixed an issue where mining Mithril would prompt an action bar notification if no XP was earned
  * Fixed an issue that caused duplication in HoTM perks

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing the Guide Menu and fixing issues as they are reported. This list is not exhaustive._
