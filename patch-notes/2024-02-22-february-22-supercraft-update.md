# [February 22] Supercraft Update

Hey all!  
  
Today we are releasing two new features related to a very core element of SkyBlock: **CRAFTING**.  
  


### **►** Supercraft​

Supercraft is a new way to craft items for [**[VIP]**](https://store.hypixel.net/category/ranks) players and above. It lets you craft a lot more items, a lot faster!  
  
You can access Supercraft by opening the Recipe page from anywhere it already exists, for example the Recipe Book, a lot of Recipe Items and NPC prompts. On top of that, there is the new **/recipe <query>** command, which lets you search every recipe in the game.  
  


![1708615393856.png](https://hypixel.net/attachments/1708615393856-png.3293372/)

  
Hoping to Supercraft a Terminator  
​

As seen in the screenshot, Supercraft is able to take items from your inventory, ender chests, backpacks and sacks.  
You're able to see a breakdown of where it takes items from aswell as a bit more information if you enable the "Advanced Mode" in your SkyBlock Settings.  
_See Settings - > Personal -> User Interface -> Advanced Supercraft_  
  


![1708615361838.png](https://hypixel.net/attachments/1708615361838-png.3293371/)

  
Supercrafting 8 Amalgamated Crimsonite​

  
Supercraft allows you set the amount of crafts that you want to do. For a lot of weapons and unstackable items, the limit is 1 craft at a time, but for items which can fit into your sacks, you're able to **craft hundreds at a time** and they will go into your sacks!  
_[Note for our savvy players: Recipes which transfer data over like enchants ARE supported unlike Quickcraft, but you can only craft 1 at time. Although if you're crafting a Lapis Pickaxe and have multiple Iron Pickaxes, Supercraft will use a random one as the source item.]_  
  


### **►** More Quickcraft Options​

You are now able to view all Quickcraft options instead of just 3.  
  


![1708615353086.png](https://hypixel.net/attachments/1708615353086-png.3293370/)

  
The "More Quick Craft Options" button in the Crafting menu​

  
Once you open the menu, you will be able to see everything that you're able to Quickcraft based on what's in your inventory.

### **►** General Changes​

**Lava Shell Necklace**  
This suite of changes should clarify what the necklace does and how it interacts with other items.  
  


![1708537122465.png](https://hypixel.net/attachments/1708537122465-png.3293229/)

  
Updated Lava Shell Necklace lore​

  * Clarified the behavior of Lava Shell Necklace in its lore. Its actual behavior did NOT change.​

  * Lesser Orb of Healing now specifies that it ignores Vitality, meaning it WILL heal through Lava Shell Necklace. This is again, only a lore change.​

  * The Ruby Power Scroll now applies a heal instead of directly setting your health, meaning it is now impacted by Mending/Vitality.​




### **►** Bug Fixes​

Some bug fixes (unrelated to crafting) were shipped along with this update!  
  
**General**  


  * Fixed the "Cooled Forges" perk granting 3x essence instead of 2x.
  * Fixed the layout of the Co-op Management Menu for 8+ members.
  * Fixed Byron's Compassion effect (from Gilded reforge) proccing when swapping weapons. It now only procs on melee hits.
  * Fixed the recipe for Lava Water Orb showing vanilla items instead of the real ingredients.
  * Fixed Sweet Flesh dropping outside of the Halloween event.
  * Fixed the spider name in the Venom Shot cast message during Arachne.
  * Fixed up the bazaar main menu layout.

**Item Requirement Checks**  
The following items now properly check if the player meets their use requirements:  


  * Lesser Orb of Healing​

  * Soulflow batteries accesory line​

  * Handy Blood Chalice​

  * Pocket Espresso Machine​


**Shen's Auction**  


  * If the number of bidders is lower than the number of upcoming winners for an item, the minimum bid amount is now correctly the amount set in the auction settings rather than the smallest bid.
  * Fixed negative bid increases.

  
**Typoes**  


  * Fixed a typo in Fetchur's compass dialogue.
  * Added missing exclamation mark in Salesman's dialogue.
  * Added a space in the Secrets action bar message.
  * Fixed the Ultimate Carrot Candy Upgrade item lore to reflect new XP value.
  * Fixed sometimes showing less than 0 clicks after Superpairs ends.

That's it for today! Enjoy!
