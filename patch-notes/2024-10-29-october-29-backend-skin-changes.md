# [October 29] Backend Skin Changes

Hello!  
  
Today we released some changes to how we handle skins in our backend. This is a technical change to how we display skins in a variety of contexts, items, mobs, cosmetics, and much more.  
  
We are aware that some items aren't stacking when they're supposed to. This is happening because you have items with both old and new NBT data. To update your items, simply drop them and pick them back up and they'll stack again.  
  
That's all for today!  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
