# SkyBlock's 7th Anniversary + SkyBlock Resource Pack News!

![banner.png](https://hypixel.net/attachments/banner-png.3580442/)

  
Hello! Happy 7th SkyBlock Anniversary to all of you! For the next week, there's a Magic Find and Skill XP Boost enabled in-game, and you'll be able to claim a Cake Hat by talking to the Simon NPC in The Hub.  
  
As part of the festivities, we'd like to share a special announcement.  
  
In the coming weeks, we'll be putting the initial version of the **SkyBlock Resource Pack** on the Alpha Network! This Alpha test will require players to be on _at least Minecraft version 1.21.11_ , but we recommend players use version 26.1 instead.  
  
This first version of the SkyBlock Resource Pack contains textures for over 800 items in the game, but will not include any of the custom menus that we have shown in the past.  
  
When this update is rolled out to the Alpha Network, and subsequently the Main Network, the SkyBlock Resource Pack will be **force enabled** and **required** in order to play SkyBlock. This does not mean it'll necessarily replace your favorite Resource Packs.

### **➥ Regarding Minecraft Versions** ​

With the release of [Minecraft version 26.2 on June 16th](https://www.minecraft.net/en-us/article/chaos-cubed-official-release-date), we'll be dropping support for 1.21.9 and 1.21.10. A few weeks after that, we'll drop support for 1.21.11. _Long story short: we recommend players to begin using Minecraft version 26.1 as soon as possible_. If you are a mod developer updating your mod from 1.21.10 to 1.21.11, we recommend you skip 1.21.11 entirely and upgrade directly to 26.1 instead.  
  
Going forward, we are only going to be supporting the latest two Minecraft drops, so when Minecraft version 26.3 releases in Fall later this year, only versions 26.2 and 26.3 will be supported.  
  


### **➥ FAQ** ​

**Will community resource packs still work?**  
Yes, probably! Most community-made SkyBlock resource packs depend on specialized mods to texture items. From our testing, it appears that most popular packs should still be able to override our own textures, but some might not.  
  
  
**Am I required to use the Resource Pack?  
Yes, the SkyBlock Resource Pack will be force enabled**. Many pieces of future content coming soon will use custom models, textures, menus, sounds, UI, and more. We know many of you have your favorite texture packs, but it would not be feasible for us to support an entirely different version of the game that didn't use the resource pack. So we have made the decision to make it a requirement in order to play the game. While the first version will only contain item textures, there is a lot more to come!  
  
**Will my computer be able to run the Resource Pack? Do I need to do anything to install this?**  
The SkyBlock Resource Pack will not be intensive to run, it will not take long to download, and it does not require any sort of setup on your end. It will be automatically sent to you when joining SkyBlock, and should cause little to no impact on game performance.
