# [October 16] 0.23.5 Bug Fixes + Changes

Howdy folks!  
  
Here is a list of the changes that we've rolled since the release of 0.23.5:  


  * Fixed an issue where Mineshafts containing Gemstone Crystals did not appear.
    * Crystal Mineshafts are now indicated in the scoreboard with the letter C _(such as RUBY_C)_
    * This update adds 10 brand new Mineshafts, one for every Gemstone type except Jasper and Opal.
    * Secondary Mineshafts (the 10 new ones we added) are now indicated in the scoreboard with the number 2 _(such as RUBY_2)_
  * Fixed an issue where Pest Traps would not always generate Pests when they were supposed to.
  * Adjusted some of the behavior of the Mosquito perk 'Bloodsucker's Betrayal'
    * When simulating Pest Trap collection after the player has left the Garden for some time, the time discount simulated is now applied to all rolled pests.
  * Reverted the changes made to Jacob's Contest medal distribution from [0.23.5](https://hypixel.net/threads/hypixel-skyblock-0-23-5-dungeonbreaker-pity-system-ironman-ws-and-more.5998589/)
    * This change inadvertently affected claiming contest rewards from pre-update. Contest rewards now in the menu are safe to claim.
  * Fixed an issue causing Primal Fear mobs to do significantly more damage than intended.
  * Fixed not being able to fish up the Frozen Spider.
    * Spoiler: ???

It can now be fished up while using the Icy Sinker.

  * Fixed a few other miscellaneous issues.

That's all folks! Thanks for the feedback, and if you find any more issues please be sure to report them [HERE!](https://hypixel.net/forums/skyblock-bug-reports.159/)
