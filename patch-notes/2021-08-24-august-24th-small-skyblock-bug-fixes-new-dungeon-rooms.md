# [August 24th] Small Skyblock Bug Fixes + New Dungeon Rooms

Hello, today we're releasing some bug fixes:  


  * Fixed the 'travel to the mushroom desert' objective not completing in some cases.
  * Bountiful reforge fixed from: 0.2 per crop broken -> 0.2 per crop. (This change was actually released with the Crystal Hollows but we didn't note it anywhere).
  * Added many missing super compactor recipes, notably block -> enchanted item varieties.

Not bugfixes but worth noting:  


  * Added a background song for the Crystal Hollows.
