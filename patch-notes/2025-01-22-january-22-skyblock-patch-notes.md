# [January 22] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest fixes that were rolled to SkyBlock in the past day for 0.21.1.  
  


  * Fixed an issue where a player's RNG meter progress would reset if they dropped a dye.
  * Fixed an issue that made dropping a dye in dungeons very common.
  * Fixed Pest Repellent attracting more pests instead of repelling them.
  * Fixed RNG Meter not giving retroactive exp progress on any public islands.
  * Fixed Dwarven Rail station sending players into the void when travelling to the Upper Mines.
  * Fixed being able to fish zone-locked Sea Creatures in any zone.
  * Fixed Pest Repellent applying even when disabled.
  * Fixed a couple barrier-related map issues in the Dwarven Mines.
  * Moved Scavenger book from the Ultra Rare to the Rare pool in the RNG meter.
  * Tweaked the Pesthunter's set bonus farming fortune.
  * Fixed Thunderbolt 7 scaling and added it to the bazaar.
  * Added the proper stats to the Golden Belt.
  * Fixed Mithril Grubber saying it gave more Mithril Powder than it did.
  * Fixed Brynmor Abiphone contact dialogue missing Abiphone symbol.
  * Fixed Compact Enchantment not working on Dwarven Quartz.
  * Made Subterranean Fisher work on all Mining Islands.
  * Increased Pure Quartz yield from 3 to 5.
  * Fixed Station Master dialogue using the wrong colors.
  * Disabled Larva Silk in the Temporal Race area.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
