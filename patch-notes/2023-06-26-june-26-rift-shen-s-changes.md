# [June 26] Rift Shen's Changes

Hello.  
  
Following feedback from players, we tweaked a few things about the motes economy so that Shen and the motes economy remains disconnected from the coins economy.  
  
**Rift-Exportable**  
Some of the items from Vampire Slayer now have the Rift-Exportable tag:  


  * Bubba Blister
  * Fang-tastic Chocolate Chip
  * Quantum Book Bundle
  * Guardian Lucky Block
  * Unfanged Vampire Part

![1687759054545.png](https://hypixel.net/attachments/1687759054545-png.3217712/)

  
Rift-Exportable/Exported tag on vamp slayer drops​

  
_Some players commented that "the damage has already been done".  
We do not think so. There are only so many slayer drops in circulation, and in 1 or 2 Shen auctions, the motes will have run out._  
  
**Other**  


  * Reduced motes value of Hemoglass from 80->25
  * Reduced motes value of Hemobomb from 1200->400
  * Fixed vampire minions being in the wrong category in the recipe book
  * Fixed more typos

Hopefully this fixes most players' gripes with the "endgame" of the rift island.
