# [March 9] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  


  * Fixed brown mushroom stems showing as wrong block variant in the Black Lagoon of the Rift
  * Fixed uncarved pumpkins not being breakable in The Barn
  * Fixed an invalid pale moss block in the Castle
  * Fixed the Spider's Den launcher to the Hub flying to the wrong location
  * Fixed some mushrooms in the Mushroom Cave being unbreakable
  * Fixed a broken door in the Fashion Shop
  * Fixed not being able to open the Ship Navigator menu by clicking nearby blocks
  * Fixed invalid chiseled bookshelf in the Wizard Tower
  * Fixed some redstone being mapped incorrectly

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!  
  
_Please note: We are still balancing and patching this release. This list is not exhaustive and is subject to change._
