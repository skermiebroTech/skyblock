**►**** Guide Menu**  
  


![Guide Intermediate.png](https://hypixel.net/attachments/guide-intermediate-png.3164370/)

  
Introducing the Guide Menu - a new feature in the game that helps players stay on track with their progress! With this menu, players can now easily view a list of specific tasks to complete at **their current stage of the game**. The Guide Menu helps keep you on the right path.  
  
_Please note that we are still balancing the Guide Menu based on player feedback and values in it are subject to change!_  
  


![Guide Intermediate Master Locked.png](https://hypixel.net/attachments/guide-intermediate-master-locked-png.3164376/)

  
The Guide Menu will split into 7 different Game Stages: Starter, Amateur, Intermediate, Skilled, Expert, Professional, and Master. You progress through the Guide by completing tasks in your current stage.  
  


![Guide Intermediate Wiki.png](https://hypixel.net/attachments/guide-intermediate-wiki-png.3164375/)

  
If you're ever confused about something in the guide, you can click it to get more information from the [Official Hypixel SkyBlock Wiki](https://wiki.hypixel.net).​

  
The Guide Menu can be accessed in the SkyBlock Leveling icon from the SkyBlock Menu!  
  
**►** **SkyBlock Menu Updates**  
  


![SkyBlock Menu \(1\).png](https://hypixel.net/attachments/skyblock-menu-1-png.3164169/)

  
_The Updated SkyBlock Menu_  
​

We've made a few changes to the SkyBlock menu to have easier use and to be less confusing for newer players.  
  


Spoiler: Why have we made these changes?

The SkyBlock Menu has remained the same ever since the game has released. As new icons were needed, they were slowly added to the main menu. Over time, this menu became more crowded and crowded. We have decided to make these changes not only to allow the main menu to look nicer but also to help with confusion towards new players. There are several icons that only show up at certain times or icons that need to be unlocked that the new player does not know about. We know a few of these changes will take some time to get used to but we believe it will be better in the long run. We first released these changes [almost 3 weeks ago on the Alpha Network](https://hypixel.net/threads/january-13-skyblock-menu-layout-and-profile-performance-alpha-testing.5234482/) to allow mod developers time to properly adjust to these changes.

  
**What exactly has changed:**  


  * Moved the Trades menu inside the Recipe Book menu
    * You can now instantly sell your items to the Booster Cookie menu if you have the Cookie Buff
    * Moved the Leveling icon to the place the Trades Menu was before
    * Added /trades as a quick shortcut into the Trades Menu
  * Moved all 5 Bags into a new Bags menu that can be accessed from the main menu
    * If you have the Cookie Buff, you can now use the following commands:
      * /accessorybag _(aliases are /accessories, /accessory, /abag, /ab, /accs)_
      * /fishingbag _(aliases are /fishbag, /fbag, /fb, /fishingb)_
      * /potionbag _(aliases are /potions, /potbag, /pots, /pbag, /potionsbag, /pb)_
      * /quiver __(aliases are /quiv, /arrowsbag, /arrowbag, /arrows)_ _
      * _The Sack of Sacks can still be accessed using /sacks without needing the Cookie Buff_
  * Moved Active Effects to Your Profile menu
  * New Booster Cookie Menu
    * You can now buy Booster Cookies directly from this menu!
    * Cookie Clicker v0.02
      * Cookie Clicker now stays across lobbies!
      * There is a Cookie Clicker ranking to view your position.
    * All players have access to this menu from the main menu
  * The Crystal Hollows - Entrance Fast Travel is now automatically unlocked when first visiting the Crystal Hollows
  * If you do not have Pets, Wardrobe, Personal Bank, or any bags unlocked it will now show locked and what is required to unlock instead of hiding from the menu
  * The Quick Warp to Jerry's Workshop has been moved to the Fast Travel menu
  * The Calendar and Events menu has been reduced to two lines for readability
  * The Upcoming Events and Personal Bank icons will now count down in the main menu in realtime
