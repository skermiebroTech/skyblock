# [June 21] Undead Patch

Hi!  
  
First, make sure to check out the latest major update: <https://hypixel.net/threads/skyblock-patch-0-19-the-rift.5399251/>  
Today, we are releasing a small patch with a few changes unrelated to the rift.  
  
**Undead Items**  
The zombie pet perk "Living Dead" has been updated to work on ALL stats instead of just defense:  
  


![1687370883410.png](https://hypixel.net/attachments/1687370883410-png.3216026/)

  
Updated Zombie pet perk​

  
Along with that, we marked all impacted armor pieces with the "undead" tag:  
  


![1687370931026.png](https://hypixel.net/attachments/1687370931026-png.3216028/)

  
Cleaned up Reaper Mask lore and added the undead tag​

  
**Lost & Found**  
There is a feature in the game which sends you items in rare cases, for example when leaving a dark auction or leaving a server at the wrong time when claiming auctions. A lot of players were confused where did these items go, so we added some additional messaging (also on top of Jerry) pointing out where to find them:  
  


![1687369912973.png](https://hypixel.net/attachments/1687369912973-png.3216017/)

  
Lost & Found notification on your private island​

  
_PS: This also adds the /jerry command on your private island._  
  
**General**  


  * Added cactus to the Delicate enchantment
  * Removed BIN limit on UNCOMMON items
  * Added to museum:
    * SOS Flare
    * Tactical Insertion
    * Annihilation Cloak
    * Blazetekk Ham Radio
    * Demonslayer Gauntlet
  * Muted players can no longer rename island NPCs

**Bugfixes**  


  * Now not sending held coins message from picking up 0 coins on a minion
  * Fixed runes obtained from gifts not getting into the rune sack
  * Fixed weapon swap on Execute enchant
  * Fixed bow swapping on Ice Walkers
  * Fixed Runaan's Bow extra arrows often not dealing damage
  * Fixed Mana Disintegrator not showing up on the lore of (SOS) flares
  * Fixed Pickonimbus not working on ender nodes on its last hit
  * Fixed Ragnarock channel being cancellable by other players
  * Brewing Mana potions now gives alchemy XP
  * Blast Protection now works on Yog Blast
  * Fixed the city project button being empty when calling Elizabeth through the Abiphone
  * Changed the abiphone interact lying that pig Sirih doesn't own an abiphone

**Note!**  
We made backend changes to potion effects and the elections systems. As a consequence, as a one-time thing, Diana gained the Mythological Rituals perk this year when she didn't have it yesterday. The election candidates and their perks may also have changed.  
  
That's it for today!  
There might be a few more changes to the Rift in the coming days which will be grouped in a patch notes later on.
