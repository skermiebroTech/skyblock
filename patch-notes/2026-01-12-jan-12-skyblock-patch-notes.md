# [Jan 12] SkyBlock Patch Notes

Howdy y'all! I've got a list of fairly significant changes and fixes that just rolled to the game:  
  
Changelog:  


  * Removed the Soul Eater damage cap while the player is in Dungeons, and reverted the damage change from 0.23.5.
    * The enchant description should be more clear as to its behavior now.
  * Lowered the damage cap of Burning Vengeance to 25m, and made the behavior more consistent to prevent dealing that damage multiple times.
  * Fixed an issue where Pest Traps would refill themselves on collection when you hadn't collected them in a long time.
  * Fixed an issue with the Enderman Pet's 'Teleport Savvy' perk sustaining when the pet was unequipped.
  * Fixed an issue with the Diana skin model.
  * Fixed some issues with legacy reforges still having stats on Mythic equipment.
  * Fixed an issue where Cocooning could give rewards multiple times under special conditions.
    * This update also re-enables cocooning.

That's all! If you have any bugs with this release (or others) that you'd like to report, please report them [HERE!!](https://hypixel.net/forums/skyblock-bug-reports.159/)
