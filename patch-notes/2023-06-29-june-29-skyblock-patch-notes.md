# [June 29] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed not getting Fishing EXP from killing Sea Creatures under very specific circumstances.
  * Fixed having to wait a very long time after missing a fish.
  * Fixed dropped coins from Talisman of Coins able to be picked up, but not being despawned.
  * Fixed some issues causing nicks / real names to show unintentionally.
  * Fixed menus closing unintentionally when a Dungeon starts.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
