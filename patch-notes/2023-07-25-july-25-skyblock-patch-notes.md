# [July 25] SkyBlock Patch Notes

Hey all!  
I am here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed being able to use the Auction House while in combat
  * Fixed the Livid Dagger sometimes incorrectly dealing double damage
  * Fixed Execute enchantment not applying to magic damage
  * Special Zealot drops now automatically go into your Sacks if possible
  * Emblems which are unobtainable on certain profiles (such as Stranded) are now hidden on those profiles
  * Fixed the Rift Guide emblem not unlocking
  * Fixed Dungeon Master emblem showing Master Mode completions instead of Floor 7 completions
  * Added an emblem for unlocking all Gold Trophy Fish and a golden variant for unlocking all Diamond Trophy Fish
  * Fixed the new nicked level calculation to better hide more end game players' levels when nicked.
  * Added extra data to the Mining Helix, Gardener, Collecting Top Hat, Magical Sigma, and Snowman Emblems

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
