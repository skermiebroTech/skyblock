# [July 1] Extreme Bingo & Bug Fixes

Hello! We've rolled out some bug fixes for the newly released Foraging content along with a few changes for the upcoming Extreme Bingo event. Enjoy!  
  


### **➥ Extreme Bingo**​

Extreme Bingo is returning today, July 1st! Will you be able to complete all of the extra-difficult tasks before July 15th? There are a few changes this time around:  


  * Added a Bingbow (Bingo Shortbow)
  * Added the Bingo Rod (Water Rod)
  * Changed the item model of the Binghoe to an Axe
  * Fixed an issue with "A Hard Day's Work" Community Goal not correctly counting Jacob's Tickets

  


### **➥ Foraging Bug Fixes**​

  * Fixed several miscellaneous issues with the Hunting Toolkit
  * Fixed several issues with loot sharing Shards
  * Fixed some related errors with getting Shard types from mobs
  * Fixed an issue regarding using Traps on Private Islands or The Garden
  * Fixed a miscellaneous issue with The Bazaar
  * Fixed an issue with the Eleanor questline in the Park
  * Fixed Heart of the Forest menu showing lifetime earned Forest Whispers instead of current Forest Whispers
  * Fixed SkyBlock XP decreasing from obtaining Forest Whispers after spending them

  


### **➥ Miscellaneous Bug Fixes**​

  * Fixed being able to drop Obfuscated Trophy Fish outside of the Crimson Isle
  * Fixed Harp Songs displaying 100% completed when they shouldn't be
  * Fixed Pumpkin and Melon Dicer 1.0's abilities dropping less items than intended
  * Fixed certain Mixins and Potion Effects not being toggleable in the Toggle Potion Effects menu
    * End Portal Fumes, Deepterror, Gabagooey, Hot Chocolate, and Jerry Candy
  * Fixed King Yolkar's foul stench persisting when it shouldn't sometimes

  


### **➥ A public notice about the Dark Auction**​

Following recent updates and backend changes to the game, we have identified a performance issue that is negatively affecting the servers right now. Though we are always working on improving performance over time, there was always the risk that things would catch up to us someday as we release more content.  
  
This has led to the Dark Auction specifically going, well, dark. We have a few potential solutions in the pipeline, but it is not possible at this time to tell how long it will take.
