# [July 18] SkyBlock Patch Notes

Hey all!  
We are here to inform you about the latest update that was just rolled to SkyBlock!  
  


  * Fixed Remnant of the Eye not working correctly. (Was fixed last week.)
  * Fixed not being able to fill Chum Buckets from Ironman players when on the same Coop.
  * Fixed Experimentation Table containing duplicate rewards. (This fixes the rare issue, where you would find two matching items, but they wouldn't count as a pair.)
  * Reduced particle effect duration from Ice Bolts to reduce visual clutter.
  * Fixed a few places in Dungeons not respecting nicks.
  * Slightly improved accuracy of Composter hologram for required Organic Matter.

  
If you have a bug to report to us, please make a report [HERE!](https://www.hypixel.net/skyblock-bugs/) Thanks to everyone who has reported bugs!
